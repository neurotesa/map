# Календарь по карте

Статический сайт, сборка не нужна. Залить папку в GitHub и подключить к Vercel.

## Как добавить месяц
1. Положить новый файл в `months/`, например `months/2028-01.js`.
2. В `index.html` добавить строку рядом с остальными:
   `<script src="months/2028-01.js"></script>`

Старые файлы месяцев не трогать — можно только добавлять новые.

## Где хранятся записи «Реальность»
В браузере (localStorage) под ключом `natal-cal-notes-v1`, отдельно от файлов прогноза.
Обновление сайта и новые месяцы их не стирают, если адрес сайта (домен) не меняется.
Пропадут, если очистить данные сайта в браузере или открыть с другого устройства.
Поэтому раз в месяц скачивайте Excel (кнопка у месяца) — его можно загрузить обратно кнопкой «Загрузить Excel».


## Два времени рождения
На всех трёх страницах есть переключатель «6:00 / 6:09». Выбор запоминается в браузере и общий для всех вкладок.
Календарь при 6:00 берёт месяцы из папки `months/`, при 6:09 — из `months-609/`. Новый месяц нужно класть в обе папки и добавлять в список MONTH_LIST в index.html.
Записи «Реальность» общие для обоих вариантов — они привязаны к дате, а не ко времени рождения.
